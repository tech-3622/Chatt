# Adaptive AI University — STA 111 (Descriptive Statistics)

An adaptive, step-by-step AI lecturing system built for Android Termux and mobile browsers.
Instead of rushing through a fixed lesson plan, an internal Understanding Engine verifies comprehension before moving forward, adapts failed explanations, and pauses to teach missing foundations using a Concept Stack.

## Modes
- CLI Private Lecture: python3 main.py
- Mobile Web App (Solo + 2-Student Shared Classroom): python3 web_server.py

## Setup (Termux)
    export GROQ_API_KEY="your-api-key"
    python3 web_server.py
